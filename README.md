# WFCditasik brand kit

Assets and rules for the WFCditasik weekly Instagram carousel.

- `style-guide.md`: colors, fonts, highlight rules, layout rules. **Start here.**
- `fonts/`: Instrument Serif, Courier Prime, Caveat (free, OFL)
- `backgrounds/`: 1080 × 1350 backgrounds (SVG + PNG)
- `ui-stickers/`: original phone/laptop UI stickers in maroon and matcha
- `paper/`: washi tape, notes, torn paper
- `highlights/`: reference render of the two highlight styles
- `photo-stickers/`: your own cut-out photos from WFC sessions
- `preview-*.png`: quick look at everything
- `tools/build_assets.py`: regenerates all SVG/PNG assets

Use the PNG versions in Canva. Use SVG when you need to resize or recolor.
