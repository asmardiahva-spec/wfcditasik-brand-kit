# Photo stickers

Your own photos only (or packs you bought with a social media license).

1. Shoot objects on the table at a WFC session: kopi, laptop, notebook, charger, the café's cups.
2. Remove the background (iPhone "lift subject" or Canva background remover).
3. Save as PNG with a transparent background, at least 1000 px on the long side.
4. Name it simply: `kopi-susu-langgam.png`, `laptop-top-view.png`.
5. Add a white outline in Canva (Effects > Shadows > Outline, white, about 8 px), or send them to Claude to add it.
